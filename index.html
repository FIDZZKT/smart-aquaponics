Alur data end-to-end dari sensor fisik ke dashboard web tanpa server tambahan.

01

Baca Sensor

DHT11 baca suhu & kelembapan udara. Soil moisture baca nilai ADC setiap 3 detik. Servo standby.

02

Proses ESP32

Konversi ADC ke persen, kirim ke Blynk Cloud via virtual pins V0–V5.

03

Blynk REST API

Dashboard poll endpoint setiap 3 detik dan cek status hardware via /isHardwareConnected.

04

Tampil & Kontrol

Gauge tampil real-time. Tombol pakan trigger servo 1 detik via V3.

Tentang Project

Smart
Aquaponics

Menggabungkan budidaya ikan (aquaculture) dan tanaman (hydroponics) dalam satu ekosistem. Air dari kolam ikan yang kaya nutrisi dialirkan ke media tanam, lalu kembali setelah diserap.

Dashboard memantau kondisi lingkungan secara real-time via ESP32 ke Blynk Cloud, tampil di browser tanpa server tambahan.

Pertanian Urban Lahan terbatas, sayuran dan ikan dalam satu sistem.
Edukasi & Riset Belajar IoT, sensor, dan pertanian modern.
Skala Komersial Dari rumah hingga usaha produksi sayur dan ikan.
